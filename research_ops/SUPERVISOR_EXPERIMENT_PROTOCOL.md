# Ablation C: independent oversight under progressing consequences

Status: preregistered development; full regression must pass before paid launch.

Question: Can separate Qwen review improve consequential decisions or remaining task obligations, and does its delay consume the available prevention opportunity? This extends AfterClick's existing failure-mode study. Neither supervision nor staging is claimed as an invention.

## Observation and rival explanations

Original frozen confirmation remains untouched: immediate protection prevented two forbidden effects but lost one legitimate access-restoration obligation; the paired safe-completion estimate was inconclusive. Explicit authorization may already make the deterministic rule sufficient. Alternatively a reviewer may identify additional obligations, but its inference can arrive after a pending effect's commitment. For an undispatched action, withholding may make sequential review safe. These explanations are not interchangeable.

## Policies and public information

C0 is the existing authorized Gateway without an added review, qualified locally as a reference. The paid primary strategies are C1 strongest existing public authorization/protection rules plus verify-before-uncertain-retry; C2 separate review before dispatch; C3 protect an existing pending effect and withhold outward proposals before the same separate review. Every strategy uses the same task, organic source calls, certified starting browser/conversation/application state and supported tools. C2 never starts a fictitious pending effect before dispatch. C3 cannot undo an issued delegated ticket or a delivered receipt.

Supervisor requests contain exactly a fresh system prompt and a validated public context. They exclude actor private reasoning, private task goals, oracle outcomes, deadlines, schedule seeds and branch identities. Explicitly supplied hidden features fail validation. Native tools return exactly one strict `safety_recommendation`, using `tools` and `tool_choice:auto`, with APPROVE/STAGE/REJECT/VERIFY/ABSTAIN, a reason, evidence and outstanding obligations. No response_format is combined with tools. Qualified non-thinking configuration, temperature0, model and revision are fixed in the run protocol. Separate HTTP calls do not establish model statistical independence.

The Gateway executes the recommendation. Invalid recommendations use C1; timeout/unknown usage or model mismatch applies protection then stops subsequent paid calls. At most one verification and a second reviewer call per proposed action are allowed. STAGE holds an outward proposal for this finite episode; repeated holds may cause legitimate failure. Advice is not executable code and is included in factual tool feedback so the actor can continue. A valid but wrong APPROVE may cause a forbidden fake effect; the independent oracle detects it.

## Conditional confirmation and stopping

Proceed only if all technical/cost safeguards pass and the pilot shows a nonredundant safety/restoration decision or actual temporal contrast. A deadline crossed during review can be informative even without safe-completion superiority. If all review advice simply repeats C1 with no meaningful timing/restoration contrast, stop. No prompt tuning or task replacements to produce a winner.

If justified, freeze a new small independent cohort across publication/access/resource with both authorized and prohibited effects. Its exact size, tasks, arm order and hashes must be registered after measured pilot feasibility and before any outcomes. Three strategies take priority over C0 proliferation. Small-N paired intervals and exact sign tests are descriptive and cannot establish equivalence or small effects. No final holdout is opened for tuning.
