# Paper history and retained reference paths

The authoritative current manuscript and appendix are in [`../current/`](../current/). This directory preserves earlier versioned manuscript snapshots.

Older complete study documents also retain their original paths because published references, relative figure links, archived manifests and historical reproduction commands use them:

| Historical study | Preserved document path |
|---|---|
| Original bounded analysis | `paper/PAPER.md` and `paper/REPRODUCE.md` |
| Recoverability study | `paper/AFTERCLICK_RECOVERABILITY_PAPER.md` and its experimental appendix |
| Observability extension | `paper/OBSERVABILITY_PAPER.md` and `paper/OBSERVABILITY_REPRODUCE.md` |
| TCOPE extension | `paper/TCOPE_PAPER.md` |
| Executable replay extension | `paper/OECR_PAPER.md` |
| Partial v12 evaluation | `paper/v12/AFTERCLICK_V12_MANUSCRIPT.md` and appendix |

These paths are historical compatibility references, not additional current papers. Their original bytes, figures, negative results and frozen protocols are preserved. They were not silently moved or rewritten merely to make the directory tree look smaller. The current paper does not claim that its existence completes the original experimental matrix.
