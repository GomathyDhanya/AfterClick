# AfterClick v12 compact evidence

These reports are byte-identical copies of completed local experimental analysis and verification. `MANIFEST.json` records each original path, SHA-256 and size. They are small enough for ordinary Git. Original raw trials, failed/invalid runs, model bodies, database/receiver snapshots and graph nodes are preserved in the separate full evidence archive, not discarded.

The study is **incomplete**: 1,479 of 2,904 registered TEST assignments have terminal records, with 1,425 unexecuted. See the complete assignment table and acceptance audit under `research_ops/completion_v12/final_package/`. Of 1,239 internal records, 1,073 are valid and 166 invalid; all 240 official external conditions were executed.

The full archive is `AfterClick_v12_Evidence_Release.tar.gz` (637,853,954 bytes; 151,623 files). Its checksum is in `data-archive/archive.sha256`; its completed read-back verification is in `data-archive/verification.json`. The archive has **not been uploaded**. Until it is attached to a GitHub release or another accessible research-data host, a fresh clone does not contain the raw evidence and cannot run full saved-data reproduction. See `docs/GITHUB_PUBLISHING.md` for the separate data upload and restore instructions.

`primary-analysis`, `larger-analysis`, `official-external-analysis`, `model-comparison` and `controlled-actuator` contain measured numerical results. Independent software-oracle, graph-extension and relocated saved-data checks are included. Report paths can reference the original author's local workspace; raw traces were not rewritten to hide this provenance.
