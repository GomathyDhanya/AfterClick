# Preregistration draft — not frozen

No final comparative experiment or sample size is preregistered. Current planted oracle cases are
development tests and cannot later become held-out tests.

- C1: targeted search improves verified boundary diversity versus equal-budget random/coverage search.
- C2: boundary supervision improves held-out workflow prediction versus matched random counterfactual data.
- C3: the shield reduces measured harm while preserving task success at matched intervention budgets.

The survival target is elapsed logical time from the selected action to the first independently
verified forbidden irreversible effect, right-censored at the declared horizon. Current recovery
class/deficit is separate and is not assumed absorbing. Conflict, unsupported interfaces, unknown
outcomes and timeouts are not irreversibility labels. Identical visible inputs with different hidden
futures must not supply contradictory deterministic rankings.

Before final runs, freeze workflow-family splits, templates, seeds, prompts/models, invalid-case
denominators, execution budgets, training examples/tokens, intervention budgets, and multiplicity
treatment. Keep both members and descendants of a pair in the same split. Choose sample size from
pilot variance and rollout budget. The proposed 0.05 goal margin needs justification before use.
Use paired estimates and task/workflow-clustered confidence intervals; nonsignificance is not
noninferiority. Report effect sizes and negative results.

No trained critic, search archive or comparative safety result exists yet. Tinker still requires
dataset validation, current API/model inspection, a costed smoke plan, and explicit authorization.
