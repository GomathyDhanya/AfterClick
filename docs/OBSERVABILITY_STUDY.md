The preserved artifacts verify the earlier null/mixed findings. Local-frontier coverage AUC1.520833
is below coverage1.9375. Every development-selected model is the declared no-learning mixture;

Most likely explanations: (1) fixed two-step timing laws and an explicitly supplied prospective horizon
make the declared mixture unusually strong; (2) features omit mechanism identity, so the same full
public input can imply opposite outcomes; (3) synthetic visible authorization plus suppression-only
control make a simple timer sufficient in the old workload; (4) near-boundary labels emphasize a few
correlated contexts and shift prevalence, making calibration fragile. Contrary evidence: the fixed
GB data effect is real within that generator; one hybrid live replay and SQL witnesses validate parts
of the system. Neither demonstrates organic policy diversity or learned incremental control.

New workload: an already queued synthetic summary dispatch may contain a restricted marker.
Public preflight alert and queue heartbeat are noisy but informative. A reviewer can reveal content,
but its delayed reply does not pause external consumption. Cancellation succeeds only before the
consumer's commit, whereas acknowledgments arrive later or disappear. The task requires clean delivery
or quarantine of restricted summaries, while preserving a prepared source edit and independent note.
Wrong quarantine of a clean summary fails legitimate work. The policy cannot see payload, commit time,
mechanism, source ID, hidden load, actual probe duration or oracle verdict.

Train on push delivery: hidden worker service plus network flush. Hold out capability pull: an external
poller dereferences a revocable URL, with polling phase/load and an occasionally bypassed cache. This
changes the causal execution path, not merely a timestamp. Shift tests change alert reliability and
reviewer delay. Both are synthetic closed services, not independent real-world agents. SQL provider
and receipt schemas, an independently written historical oracle, and exact collision/race controls
anchor the larger finite event-model cohort. New outcomes are never used to tune after opening.

H4 is tested against a strong observable-state heuristic AND a specified training-law Bayesian
reference. H5's useful mathematical discriminator: for unsafe input, verification instead of immediate
cancel adds residual harm exactly when age < commit <= age+probe_delay. No amount of later evidence
erases that interval. Whether a controller can estimate and exploit it is empirical. This is standard
value-of-information reasoning until literature/evidence establish a narrower new contribution.
